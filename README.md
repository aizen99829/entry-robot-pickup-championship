# The Robot Pickup Line Championship

One robot pickup line, delivered by `main()` in `main.ts`.

**The line:** "I don't have a heart, but my cooling fans hit max RPM every time you walk by — and my warranty doesn't cover this."

Why this line: a robot has no heart, but its cooling fans are real hardware —
when they spin up to max RPM, the machine is overheating, which is a robot's
version of blushing. The warranty tag adds a second beat: falling in love
treated as a malfunction the manufacturer won't cover.

The line is validated to be a single line of 1–200 characters, never blank.
